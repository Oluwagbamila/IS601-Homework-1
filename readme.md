Command 1
git init
initialize an existing directory as a Git repository

Command 2
git branch
list your branches. a * will appear next to the currently active branch

Command 3
git clone [url]
retrieve an entire repository from a hosted location via URL

Command 4
git commit -m “[descriptive message]”
commit your staged content as a new commit snapshot

Command 5
git merge [branch]
merge the specified branch’s history into the current one

Command 6
git rebase [branch]
apply any commits of current branch ahead of specified one

Command 7 
git log branchB..branchA
show the commits on branchA that are not on branchB

Command 8
git mv [existing-path] [new-path]
change an existing file path and stage the move

Command 9 
ls -lh 
displays file sizes in a human-readable format.

Command 10
cd /path/to/directory
changes the current directory to the specified path.

Command 11
mkdir my_directory
creates a new directory named "my_directory".

Command 12
rm file.txt
deletes the file named "file.txt"

Command 13
cp -r directory destination 
copies the directory "directory" and its contents to the specified destination.

Command 14
mv file.txt new_name.txt 
renames the file "file.txt" to "new_name.txt".

Command 15
touch file.txt 
creates an empty file named "file.txt".

Command 16
cat file.txt 
displays the contents of the file "file.txt".
